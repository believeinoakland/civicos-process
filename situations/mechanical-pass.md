# Situation: the same mechanical change across many modules (P7 "a mechanical change is one pass")

(1) State the change as a rule a script or worker applies the same way in every module, and take the list of modules from a check's findings, never by hand. (2) No job is running. (3) One worker (sonnet, medium) applies it on the tranche branch and lists every module where the rule needs a judgment: each of those becomes an entry of its own job in this round or the next. (4) Every module's tests, the checks and the generated artifacts run once; every red is fixed before the commit; no red is accepted and no module dropped to make the run green. (5) Read the diff's summary and every line the worker marked uncertain, then commit. (6) A ruling names the rule, every module touched, every module handed to its own job, and the test result.
