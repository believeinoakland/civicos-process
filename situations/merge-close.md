# Situation: merging a job; closing a layer, a round, the tranche (P7, P10, P12, P14)

- **Merge** as soon as a job is COMPLETE: `proc merge --module <m>`. It refuses unless the record reads COMPLETE; runs ownership against the merge base, merges with a merge commit, runs the module's tests and the checks (and undoes the merge if anything is red), strikes the met `*(not yet met: T<n>)*` marks the report names, writes the ruling line, pushes and verifies on origin. For an extraction, read every `ADDED` line ownership lists. `proc merge` merges nothing red: a red is fixed by the job, or its entry re-scoped with the job (`situations/messages.md`, blocked).
- **Close a layer** when every job of it is merged and none is re-opened: regenerate the product's generated artifacts as its manifest says and commit them; `proc layer close --layer <L>`; archive each session it lists (`archive_session`), writing each row with `proc job archived --module <m> --usage '<archive usage json>'`; start the next layer.
- **Close a round** after its last layer: `proc round close` (archives its plan whole); open the next round at once if it has entries.
- **Close the tranche** after its last round: merge the design stream's PR if it asked (`MERGE`), then `main` into the tranche (never a rebase), run every module's tests and the checks, set the plan's Status `CLOSING`, open the PR `tranche/T<n>` to `main` and merge it with the GitHub merge tool (method `merge`; the hook allows it only once CLOSING); delete your backstop; report to Bob in plain words: elapsed time, what was finished, what was left and why, what it cost (P14, P19). Open the next tranche at once.
