# The writer test (issue 61; DRYRUN §8)

Fresh headless writer sessions (`claude -p`, acts.md) each get one situation from `situations.json` (the tool output of a real kind of Bob-facing report) in their own clone of this repository, with the role `process` recorded and both checks live, and write the turn-end message to Bob. `analyze.py <run dirs>` prints every draft and verdict from the transcripts; `summary.py` the counts and the plain-words check on each final; `judge2.sh <run>` an independent Opus judgment (understandable, accurate, act clear). `reader.sh <model> <i> <tag>` runs the reader's prompt alone on `corpus.json[i]` (36 labelled messages, plus Bob's report). Set `SCRATCH` to a scratch folder; the scripts write there, never here. Paths inside `analyze.py` and `summary.py` are relative to `$SCRATCH/wt`; `judge2.sh` and `reader.sh` read the reader's prompt from `$SCRATCH/reader-prompt.txt` (extract it from `.claude/skills/neoprocess-reader/SKILL.md`).
