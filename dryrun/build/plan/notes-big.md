# Working notes: the toy's plan documents (dry run)

**Status** · A working document of the toy product's plan, read whole by every session that takes the plan up. Written for the dry run D17 (the size gate, bio K5015) to be over the limit of 51,200 bytes on purpose. Section 1 holds a finished round's notes, moved whole to the archive when the round is over; section 2 holds what is open; section 3 is standing reference that stays.

§1 moved whole to `build/plan/archive/notes-big-s1.md` (D17, SG4).
